1.课表页面要求直接显示七天的课程安排，而不是点击查看某一天的。课表的最上面，可以自定义自己最喜欢的名言警句。  
2.要求课表页面的下边就是一个极简形式的todolist，点击todolist可以创建前面带括号的items，完成事项就点击括号，括号变成✅表示任务完成。  
3.todolist旁边要求是ddl list，点击其可以创建items，items后面带固定格式的日期，要求创建item的时候填写日期，例如09/3表示九月三日。  
4.todolist的创建要求也会记录到月历当中，会在月历日期下面出现绿点表示有todolist，ddl list的创建也会规划到月历当中，要求月历日期下面出现较绿色点大一点的红色点。点开日期，会在月历下边出现todolist和ddl list依旧是以绿点红点区分开来。月历要求能够在日期数字的下边显示ddl的名称，如若名称太长自动省略。  
5.自习室要求页面极简，但是提供可更换的主题。  
6.自习室的番茄钟组件要求能够自主创建20分钟到180分钟不等的番茄钟，能够命名，也能够自定义番茄钟事项小组件的背景图片，创建出来后显示名称和专注时长。创建的方式要求是在组件右上方的一个“+”号。要求能够左右滑动窗口选取自己创建的番茄钟小分块，一次性显示六个番茄钟的分块，大小一致，均分番茄钟大组件的窗口页面。  
7.番茄钟下面要求的是“自习室”区块，需作区分，该工具的自习室指的是线上自习室而不是线下自习室。所以要求线上自习室有一个加号，点击的时候能够出现“创建自习室”“加入自习室”选项，自习室按照加入时长成顺序排列，点开“全部”标签能够检索或者滑动窗口找到自习室。自习室的室主有权对自习室进行背景图片的更换。  
8.加入自习室之后，会进入“自习室”页面，上面会显示自习的人员与id，下面有聊天窗口，但输入不会实时弹出，只有点进聊天窗口的时候才会接受新的消息。  
**以上是v2.0的想法**

# **v3.0想法**
1.为了参加小红书工具，在现有基础上将整个页面风格改为国风画面，自定义ui保留不变。  
2.线上自习室提供bgm选择，外部接入qq音乐、网易云音乐、apple music等各大音乐软件，使用自己的歌单。  
3.在todolist ddllist上面提供一个便签功能，页面视图看起来和现实中的普通便签一样，允许用户在上面随意书写。  
4.**个性化**：将各个区域分为小组件，提供自定义ui服务。能够自定义添加移动小组件，使用装饰性小组件。  
5.在课表上应该标出中国的法定节假日，如“周四 04 清明节”  
6.课表的时间栏要求能改动，同时能够自主添加课时（不与导入课表数据冲突）  
7.番茄钟要求记录每个番茄钟的专注时长。  
8.加入自习室之后仍然保证有番茄钟的专注计时（进入自习室之后仍然想记录干了什么事）  
9.“课表”栏名称改成“主页”栏，要求在“名言警句”上面置入一个星星按钮，点开之后在里面记录自己对自己这一学期的规划。  
8.对于ddl、todo的完成情况，所有番茄钟的专注时长（要求细致记录：某一天的总专注时长，每个类别的分别专注时长）要有记录，自习室同理。每个月定期生成studyhub月报，对ddl todo和专注、自习时长进行总结，对用户给予鼓励。每一学期结束了，就用户完成的todo ddl 番茄专注、自习时长与目标实现进行总结，生成一个可交互的页面，比如说“你过去的一学期，有50天学习到深夜”然后点击屏幕，出现下一句总结。  
9.“名言警句”部分要求有三种功能，第一种固定名言警句，自己自定义输入，每天都一样；第二种随机名言警句，每天随机放置该工具名言警句库的一段内容；第三，每天随机用户自己的名言警句库（这联系到另外一个功能，要求有一个名言警句便签，用户可以就看的电影书籍等作品将名言警句记录其中，然后在“我的”一栏能够点开查看）。
